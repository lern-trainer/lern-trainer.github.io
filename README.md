# Übungsraum – interaktive Übungstrainer

Startseite: `index.html` (GitHub Pages, Branch `main`, Ordner `/`).
Jeder Trainer ist eine einzelne HTML-Datei unter `<fach>/<thema>/index.html` –
offline lauffähig, ohne Anmeldung, ohne Tracking, ohne Verbindung zu Dritten.

## Neuen Trainer hinzufügen

Wird vom Lehrer-Plugin (Skill `trainer`) erledigt: Trainer bauen, dann
`startseite_bauen.py` – Karte und `trainer.json` entstehen von selbst. Danach
committen und pushen. `index.html` und `trainer.json` nicht von Hand ändern.

Schriften in `fonts/`: SIL Open Font License 1.1 (Lizenztexte daneben).
